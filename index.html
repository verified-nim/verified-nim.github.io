A copy hook that reads freed memory

=dup hooks that run on garbage

Copy into raw storage and the compiler injects a =sink that treats uninitialized memory as live. Our skill had the right pragma for the wrong reason. A compiler-run test now pins the rule.

Questions

Don’t strong models already know Nim?

Knowing Nim still leaves room for memory-safety bugs, and a passing build won’t show them. The skills tell the agent which extra checks to run. See the trial results.

They’re markdown files. What am I paying for?

Nim instructions your agent loads, checked against the compiler and kept current as Nim changes. NYX installs and updates them. When a test shows the guidance is wrong, we fix it and the fix arrives in your next update.

Do the skills make the agent cost more?

Much of the cost is your time reviewing unfinished work and sending the agent back. The skills have the agent check more itself, like confirming a bug reproduces and reading sanitizer output. API cost per passing run was lower on DeepSeek V4.1 Flash.

I already use Context7 or another docs MCP. Do I need this?

Yes. Docs help the agent look things up, and some include examples. The skills are maintained, compiler-tested instructions for doing Nim work, like checking ownership edge cases and confirming a bug reproduces. Keep the docs MCP for API details.

Will my agent actually use the skills?

NYX installs the skills where your agent looks for them. Add the pointer to AGENTS.md or CLAUDE.md so it loads the matching skill before Nim work.
