What changes when your AI coding agent uses Verified Nim Skills

A blind, pre-registered test on DeepSeek V4.1 Flash and GPT-6.1 Sol: the same working code, with the careful work done in nearly every run.

What changes in your agent’s work

Both models wrote correct Nim either way. The difference was in how they worked. With the skills:

  • Bug reports come with a tested reproducer and a measured failure rate.
  • Ports record every bug they inherit.
  • Untrusted input is validated once, at the trust boundary, and data the compiler already checked is not checked again.
  • The sanitizer setup actually reports memory faults.

The results

Runs passed every check 56 of 57 times with the skills and 18 of 59 without, at maximum and at low reasoning effort.

Pooled lift by row: +0.80, +0.63, +0.73 and +0.51, each with p ≤ 0.0011.

On the two control tasks, where no lift was expected, runs passed 17 of 18 times with the skills and 18 of 18 without.

Correctness was level: 74 of 75 runs with the skills and 77 of 77 without passed the build, tests and output parity. The skills change how your agent works, not whether its code compiles.

Leave out the checks that only test conventions, and the lift is still +0.60 and +0.40 at maximum effort, +0.53 and +0.31 at low.

Cost per passing run

With the skills, the agent often does more work in a run, yet each passing run costs less. On DeepSeek V4.1 Flash, the API-priced model, a passing run cost $0.096 instead of $0.147 at maximum effort, and $0.039 instead of $0.072 at low effort.

How we tested

We pre-registered the study before any run. Agents worked blind in fresh sandboxes on 7 private Nim tasks: 5 that test skill-specific work and 2 controls, across bug reporting, porting, error handling, ownership hooks and debugging. Each model ran each task 3 times per effort level, with and without the skills. A run passes only when every check passes.

Limitations

Three runs per cell. Seven in-house tasks, withheld to keep them out of training data. Two models. At maximum effort, GPT-6.1 Sol covered 5 of the 7 tasks and ran no controls. The without-conventions measure was added after pre-registration.
