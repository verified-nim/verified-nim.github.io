From payment to installed skills

  1. Connect your GitHub account

    After checkout, open the customer portal (also linked in your receipt email) and connect GitHub on the “GitHub repository access” benefit. That is the account we invite.

    Team: assign each seat to a teammate’s email in the portal; they claim it within 24 hours and connect their own GitHub account.

  2. Accept the repository invitation

    GitHub emails you an invite to verified-nim/skills. Accept it at github.com/verified-nim/skills/invitations while signed in to that account.

    Invites expire after 7 days. Reconnect GitHub in the portal to get a new one.

  3. Sign git in to GitHub

    NYX fetches with git and never prompts for a password, so git must already reach the repository:

    The last command should list refs without asking for anything. Git Credential Manager works too. For an SSH key, have git fetch GitHub over SSH: git config --global url."git@github.com:".insteadOf https://github.com/

    Using a fine-grained personal access token?

    It must list verified-nim/skills under Repository access, with Contents: Read. Accepting the invite does not add the repository to an existing token. Without it, git fails with 403 or 404. Edit the token at GitHub → Settings → Developer settings → Fine-grained tokens, or use gh auth login instead.

  4. Install NYX

    Requires git. NYX is open source: planetis-m/nyx.

  5. Run NYX in your project

    Pick your agents and skills in the wizard. Detected agents start ticked. Run nyx once in each new project.

  6. Tell your agent the skills exist

    Agents load skills far more reliably when told they exist. Add a pointer to AGENTS.md or CLAUDE.md:

    Naming the skill in your prompt works too.

After setup

nyx
Shows this project’s status and checks for skill updates at most once every 30 days.
nyx update
Updates skills now, in every project and the user scope.
nyx setup -g
Installs into your user-level skill directories instead of one project.

Supported agents: Claude Code, Codex, Cursor, GitHub Copilot, OpenCode, Windsurf, Cline, Roo Code, Continue, Crush, Amp, Goose, Antigravity and Pi.

Every command, skill directory and environment variable is in the NYX README.

Cancelling

Cancel in the customer portal. Renewals stop and repository access ends with the paid period.

repository unreachable

Git never prompts for credentials; missing access leaves installed skills in place. You keep using the versions you received under the license. Updates stop.

To remove skills from a project yourself, run nyx remove. It removes only what NYX created and leaves skills you edited alone.
