onboarding

From payment to installed skills

  1. Connect your GitHub account

    After checkout, open the customer portal (linked in your receipt email, or at https://polar.sh/verified-nim/portal) and connect GitHub on the "GitHub repository access" benefit. This tells us which account to invite.

    Team: assign each seat to a teammate's email in the portal. Each teammate claims the seat (the link is valid 24 hours and can be resent) and connects their own GitHub account.

  2. Accept the repository invitation

    GitHub emails you an invite to verified-nim/skills. Accept it at https://github.com/verified-nim/skills/invitations while signed in to that account. Invites expire after 7 days; reconnect GitHub in the portal to get a new one.

  3. Let git reach the repository without prompting

    NYX does not prompt for passwords, so sign git in to GitHub first:

    Git Credential Manager or an SSH key work too.

  4. Install NYX

    Requires git. Source.

  5. Run NYX in your project

    Pick your agent targets and skills in the wizard. Run nyx once in each new project, or nyx setup -g for user-level skill directories.

  6. Tell your agent the skills exist

    Agents load skills far more reliably when told the skills exist. Add this pointer to AGENTS.md or CLAUDE.md:

    Naming the skill in your prompt works too.

  7. Stay updated

    Running nyx checks for updates at most once every 30 days. Force it any time:

Cancelling

Cancel in the customer portal. Repository access ends when the paid period ends. Access starts as soon as you connect GitHub, and from then on payments are non-refundable. Cancelling stops future renewals; it does not refund the current period.

repository unreachable

Git never prompts for credentials; missing access leaves installed skills in place. You keep using the versions you received under the license. Updates stop.

To remove skills from a project yourself, run nyx remove. It removes only what NYX created and leaves skills you edited alone.
